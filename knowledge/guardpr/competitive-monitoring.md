# Competitive Monitoring Guide

## Google Alerts Setup

Set up the following Google Alerts at [google.com/alerts](https://www.google.com/alerts):

| Keyword | Purpose |
|---------|---------|
| `"GitHub Copilot Autofix"` | Track Copilot Autofix feature updates and pricing changes |
| `"Snyk" "auto fix" OR "autofix"` | Monitor Snyk's auto-remediation capabilities |
| `"CodeQL" "auto fix" OR "autofix"` | Track CodeQL's move toward automated fixes |
| `"Pixee" OR "pixeebot"` | Monitor Pixee's feature announcements and integrations |
| `"GitHub Action" "security" "auto fix" "pull request"` | Discover new entrants in the automated security fix space |

### How to set up

1. Go to [google.com/alerts](https://www.google.com/alerts)
2. Enter each keyword exactly as shown above (including quotes)
3. Set frequency to "Once a week"
4. Set sources to "Automatic"
5. Set language to "English"
6. Deliver to your email

## Review Cadence

- **Monthly**: Review alerts and update `competitive-log.md` with significant changes
- **Quarterly**: Review the README comparison table for accuracy and update if needed
